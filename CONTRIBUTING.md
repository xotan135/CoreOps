# Contributing

Contributions are welcome through GitHub issues and pull requests.

1. Discuss substantial behavior or user-interface changes in an issue first.
2. Create a focused branch and include tests or manual verification notes where appropriate.
3. Run `dotnet build NetworkAdmin.slnx -c Release` before opening a pull request.
4. Do not commit compiled releases, credentials, internal hostnames, confidential workbooks, or organization-specific paths.
5. By submitting a contribution, you agree that it may be distributed under the MIT License.

Changes from contributors who do not have direct repository access require maintainer review. Release builds and signing requests are approved by the project maintainer.
